# دليلي المدرسي — منتجات رقمية

نسخة عرض بنفس واجهة برنامج الاستعلام لمدرسة الزهراوي، مع استبدال شعار المدرسة واسمها بمنتجات رقمية. لم تُعدَّل نسخة المدرسة أو تُنقل بيانات طلابها.

الرابط: https://activitiesclass.github.io/school-lookup/

## بيانات العرض الوهمية
- سالم أحمد سعيد الحارثي — الخامس، الشعبة ١.
- مازن خالد علي العبري — الثامن، الشعبة ٢.
- محمد علي سعيد — تشابه أسماء؛ أضف الشحي أو الرواحي.

يحتوي data.js على بصمات SHA-256 لصيغ الأسماء الوهمية، متوافقة مع محرك البحث الأصلي. لا تُعد بصمات الأسماء آلية تحقق من الهوية، ولا يُنصح بوضع بيانات حقيقية في مستودع عام.

بقي ترتيب الواجهة وسلوك البحث والإدخال الصوتي مأخوذًا من المرجع. أضيفت أربعة ثيمات (زمردي وأزرق وبنفسجي وليلي)، وخلفيات متناسقة للبنر والصفحة، وحركة خفيفة للشعار مع زر لإيقافها واحترام تفضيل تقليل الحركة. تظهر توضيحات موضع شعار المدرسة واسمها عند مرور الماوس أو التركيز بلوحة المفاتيح أو الضغط على الجوال. يحفظ تفضيل المظهر والحركة فقط محليًا، ولا تحفظ أسماء البحث.
