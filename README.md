# دليلي المدرسي — منتجات رقمية

نسخة عرض للاستعلام عن صف الطالب وشعبته. جميع الأسماء والنتائج مصطنعة للعرض، ولم تُنقل بيانات طلاب مدرسة الزهراوي.

- واجهة عربية متجاوبة مع مظهر فاتح وداكن.
- بحث بثلاثة أجزاء أو أكثر، مع المحافظة على الترتيب ومعالجة تشابه الأسماء.
- دعم اختلاف الهمزات والتشكيل و«بن» و«عبد الله».
- إدخال صوتي في المتصفحات الداعمة، ونسخ النتيجة.
- رابط الشركة: https://activitiesclass.github.io/digital-products/
- تفاصيل المنتج: https://activitiesclass.github.io/digital-products/programs/school-lookup.html
- العرض: https://activitiesclass.github.io/school-lookup/

## الملفات
`index.html`، `style.css`، `theme.js`، `script.js`، `data.js`.

## التشغيل
استضافة الملفات عبر HTTP، أو GitHub Pages. لا توجد خطوة بناء أو مكتبات JavaScript مطلوبة. الخط العربي وشعار الشركة يحملان من مصادر خارجية؛ توجد خطوط بديلة عند تعذر الاتصال.

## اختبار بيانات العرض
- سالم أحمد سعيد: نتيجة واحدة، الصف الخامس، الشعبة ١.
- مازن خالد علي: نتيجة واحدة، الصف الثامن، الشعبة ٢.
- محمد علي سعيد: اسمان متشابهان؛ أضف الشحي أو الرواحي.
- عبد الله محمد ناصر: يقبل الصيغة المتصلة والمنفصلة.
- خالد سعيد سالم: يقبل حذف «بن».

## تخصيص نسخة حقيقية
عدّل هوية المدرسة والعام الدراسي بعد توفير بيانات مصرح باستخدامها. لا تضع أسماء حقيقية أو بيانات حساسة في `data.js` بمستودع عام. النسخة الحالية واجهة عرض ثابتة، وليست نظام تحقق من هوية ولي الأمر. الخدمة الحقيقية ذات الوصول المقيد تحتاج تحققًا على الخادم وبيانات خاصة؛ لا توفر بصمات الأسماء أو قيود المحاولات في المتصفح بديلًا عن ذلك.

الإدخال الصوتي اختياري وقد يعتمد على خدمة المتصفح لمعالجة الصوت. لا تحفظ هذه الواجهة أسماء البحث في التخزين المحلي؛ يحفظ تفضيل المظهر فقط. لا توجد تحليلات أو أدوات تتبع مضافة.
